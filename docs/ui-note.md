# UI 说明：瞭望

- **谁在什么时刻打开**：给跟进某个开源领域的技术负责人。
- **首屏任务句**：本周，哪几件事值得看。
- **主操作**：按「定主题和来源 → 合并同一事件 → 出一期团队简报」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：一期杂志；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：一期杂志。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给跟进某个开源领域的技术负责人：按主题收集仓库与发布，合并同一事件，每条保留原始来源、发生时间和“为什么值得看”。
